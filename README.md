# Netflix Landing Page 🎬

A Netflix-inspired landing page built with HTML, Bootstrap, and custom styling. The page showcases *Money Heist: Korea – Joint Economic Area* with a cinematic video background, episode cards, show information, and horizontally scrollable content.

## 📸 About the Project

This project is a front-end web development practice project designed to recreate the look and feel of a streaming platform's show-details page.

### Features

- Video background with blur and dark overlays
- Responsive layout using Bootstrap
- Episode cards with descriptions and thumbnails
- Horizontally scrollable episode and recommendation sections
- Show details, including cast, genre, release year, and subtitles
- Custom typography using Google Fonts
- Dark theme inspired by Netflix's visual style

## 🛠️ Technologies Used

- HTML5
- Bootstrap 5.3.8
- CSS3
- JavaScript
- Google Fonts
