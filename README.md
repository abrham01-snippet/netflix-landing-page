# Netflix Landing Page 🎬

A Netflix-inspired landing page built with HTML, Bootstrap, CSS, and JavaScript. The page showcases *Money Heist: Korea – Joint Economic Area* with a cinematic video background, episode cards, show information, and horizontally scrollable content.

## 🌐 Live Demo

**[Visit the Netflix Landing Page](https://abrham01-snippet.github.io/netflix-landing-page/)**

> If the website is not available yet, enable GitHub Pages in your repository settings. The link will work once deployment completes.

##  About the Project

This is a front-end web development practice project inspired by the look and feel of a streaming platform's show-details page.

The page features a dark theme, cinematic backgrounds, show information, episode previews, and recommendation sections.

##  Features

-  Video background with blur and dark overlays
-  Responsive layout using Bootstrap
-  Episode cards with descriptions and thumbnails
-  Horizontally scrollable episode and recommendation sections
-  Show details, including cast, genre, release year, and subtitles
-  Custom typography using Google Fonts
-  Dark theme inspired by Netflix's visual style

##  Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript
- Google Fonts

## Run Locally

### Prerequisites

- A web browser
- Python 3 (optional, for running a local web server)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/abrham01-snippet/netflix-landing-page.git
   ```

2. Navigate to the project directory:

   ```bash
   cd netflix-landing-page
   ```

3. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open the following URL in your browser:

   http://localhost:8000

Alternatively, open `index.html` directly in your browser.
